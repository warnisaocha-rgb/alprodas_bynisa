Praktikum 1 Bagian D

Kasus 1: Perhitungan Luas Lingkaran (const float & rumus)

Mendeklarasikan konstanta const float PHI = 3.14; dan jari-jari float r = 2.5; lalu menghitung L = PHI * r * r;. 

const float PHI = 3.14f;
float r = 2.5f;
float L = PHI * r * r;
cout << "Luas lingkaran adalah: " << L << " Cm" << endl; // Output: 19.625

Praktikum 3.1

Struct Paket Internet "Begadang"

Menyimpan kumpulan atribut paket kuota (nama_paket string, kouta_telpon int, kouta_internet int) dalam satu objek begadang. 

struct paket_internet {
    string nama_paket;
    int kouta_telpon;
    int kouta_internet;
} begadang;
Praktikum 3.3

Enum Urutan Presiden RI

Enum mengindeks otomatis mulai dari 0 (Soekarno=0, Habibie=2, Jokowi=6). Untuk menampilkan urutan presiden tinggal ditambah 1: presiden + 1. 

enum namaPresiden {
    Soekarno, Soeharto, Habibie,
    Megawati, Gusdur, SBY, Jokowi
};
