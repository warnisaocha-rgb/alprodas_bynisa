Bedah Teori Mendalam: Variabel, RAM & Tipe Data Dasar

Materi Ujian Responsi Modul 1

Buat adik-adik yang nggak punya buku teks yang sama atau merasa modul praktikum terlalu ringkas, ini catatan rangkuman lengkap yang wajib kalian pahami sebelum maju asistensi ke dosen pembimbing!

🧠 1. Kenapa C++ Butuh Tipe Data? (Arsitektur RAM)

Bahasa C++ adalah bahasa statically-typed. Artinya, compiler wajib tahu ukuran memori yang harus dipesan ke RAM sebelum program dijalankan:

  • Deklarasi (int x;): Memesan 4 byte kapling memori kosong di RAM (misal beralamat 0x7ffee4).
  • Inisialisasi (int x = 10;): Memesan kapling sekaligus mengisi angka 10 biner ke dalam kotak tersebut.
  • Assignment (x = 25;): Menimpa isi kapling yang sudah ada dengan nilai baru.
💡 Hati-Hati Garbage Value: Kalau kamu deklarasi int skor; tanpa diberi nilai awal, lalu langsung dicetak (cout << skor;), nilainya akan berupa angka sampah acak (misal: -858993460) bekas sisa program lain di RAM!
⚖️ 2. Signed vs Unsigned & Float vs Double

Memilih tipe data yang pas adalah tanda programmer cerdas yang hemat memori:

  • Signed vs Unsigned: int biasa memakai 1 bit tanda minus (-2 miliar s.d. +2 miliar). Kalau kita tambah unsigned int, angka minus ditiadakan sehingga jangkauan positifnya melonjak 2x lipat (0 s.d. 4,2 miliar)! Cocok untuk umur, harga barang, atau ID mahasiswa yang mustahil negatif.
  • Float vs Double: float memakai 4 byte (presisi 6–7 digit koma), sedangkan double memakai 8 byte (presisi 15–17 digit koma). Untuk kalkulasi ilmiah dan keuangan, selalu pakai double agar komanya tidak meleset.
char huruf = 'A'; // 'A' itu di RAM sebenarnya disimpan sebagai angka ASCII 65!
🔒 3. Konstanta: Mengapa Dosen Menyarankan const?

Konstanta adalah variabel yang nilainya dikunci mati setelah ditetapkan (read-only):

Cara Modern (Direkomendasikan): const float PHI = 3.14f; → Memiliki tipe data jelas, dicek oleh compiler (*type-safe*), dan terikat aturan *scope* blok kurung kurawal.
Cara Klasik: #define PHI 3.14 → Dikerjakan oleh preprocessor sebelum kompilasi seperti operasi *Find & Replace* buta tanpa pengecekan tipe data.
⚠️ 4. Jebakan Batman Pemula & Kisi-Kisi Responsi Dosen
1. Jebakan Pembagian Bulat (Integer Division):
int a = 5, b = 2; float c = a / b; → Nilai c adalah 2.0, BUKAN 2.5! Karena integer dibagi integer hasilnya dipotong ke integer. Solusi: tulis (float)a / b atau 5.0 / 2.
2. Petik Tunggal vs Petik Ganda:
'A' adalah karakter tunggal char (1 byte). Sedangkan "A" adalah string (2 byte karena ada karakter penutup \0). Jangan terbalik!
3. Pertanyaan Dosen: "Apa itu Integer Overflow?"
Jawab: Jika tipe short (maks 32767) ditambah 1, nilainya akan melompat ke angka negatif minimum (-32768) seperti odometer speedometer motor yang berputar balik ke nol!

Bedah Teori Mendalam: Operator, Bitwise & Logika C++

Materi Ujian Responsi Modul 2

Jangan cuma menghafal rumus di laprak tanpa tahu cara kerjanya! Berikut konsep logika operator yang paling sering ditanyakan dosen penguji saat kalian ujian praktikum:

🔢 1. Klasifikasi Operator Menurut Jumlah Operand

Operand adalah data atau variabel yang dioperasikan:

  • Unary (1 Operand): Cuma butuh 1 variabel. Contoh tanda minus -x, negasi logika !lulus, serta penaikan nilai ++x / --x.
  • Binary (2 Operand): Butuh 2 nilai kiri & kanan. Contoh penjumlahan a + b, pembanding x >= y, logika a && b, dan penugasan total = 100.
  • Ternary (3 Operand): Satu-satunya operator C++ dengan 3 bagian. Singkatan if-else 1 baris yang elegan: (kondisi) ? nilaiJikaTrue : nilaiJikaFalse;.
string hasil = (ipk >= 3.5) ? "Cumlaude" : "Sangat Memuaskan";
⏱️ 2. Modulo (%) & Pre vs Post Increment

Dua konsep yang paling sering bikin nilai kuis maba anjlok:

Operator Modulo (%): Menghasilkan sisa bagi bilangan bulat. Hanya bisa untuk tipe integer (TIDAK BISA untuk float)! Paling sering dipakai untuk cek genap/ganjil (x % 2 == 0) dan konversi satuan (misal 130 menit = 130/60 jam dan 130%60 menit).
Pre (++a) vs Post (a++):
• b = ++a; → Tambah dulu nilai a di RAM jadi 6, baru simpan ke b (hasil: a=6, b=6).
• b = a++; → Simpan dulu nilai lama 5 ke b, baru setelah baris selesai a di RAM bertambah jadi 6 (hasil: a=6, b=5)!
⚡ 3. Keajaiban Bitwise Shift (<< dan >>) di Praktikum 2.2

Kenapa di Praktikum 2.2 nilai a = 1 yang di-shift <<= 3 tiba-tiba berubah jadi 8? Dan b = 10 yang di-shift >>= 1 berubah jadi 5?

  • Left Shift (<< n): Menggeser bit biner ke kiri. Setiap 1 geseran sama dengan mengalikan dengan 2! Jadi 1 << 3 sama dengan \(1 \times 2^3 = 8\).
  • Right Shift (>> n): Menggeser bit biner ke kanan. Setiap 1 geseran sama dengan membagi dengan 2! Jadi 10 >> 1 sama dengan \(10 / 2^1 = 5\).
💡 Kenapa dipakai? CPU komputer mengeksekusi bitwise dalam 1 siklus clock prosesor, ribuan kali lebih cepat daripada operasi perkalian/pembagian aritmatika biasa!
⚠️ 4. Jebakan Batman & Presedensi Operator
1. Jebakan Fatal: '=' vs '=='
= adalah memasukkan nilai (penugasan). Sedangkan == adalah membandingkan kesetaraan. Kalau kamu tulis if (x = 5), nilai x akan dipaksa jadi 5 dan selalu dianggap TRUE oleh C++!
2. Logika Short-Circuit:
Pada A && B, jika syarat A sudah salah (FALSE), C++ langsung berhenti tanpa mengecek B. Begitu juga pada A || B, jika A sudah benar (TRUE), B diabaikan!
3. Urutan Hitung (Presedensi):
Perkalian/pembagian/modulo (* / %) selalu dikerjakan lebih dulu daripada tambah/kurang (+ -). Gunakan selalu tanda kurung () jika ingin memprioritaskan hitungan!
PRAKTIKUM 3 Tipe Data Bentukan Bagian 1

Tipe Data Bentukan: Struct, Union, Enum, Typedef

Mengapa tipe data bentukan diciptakan? C++ menyediakan 4 pilar konstruksi tipe data kustom: Struct untuk membungkus banyak variabel ke dalam kapling memori mandiri, Union yang menghemat RAM dengan memori bersama, Enum untuk daftar konstanta berurutan mulai dari 0, dan Typedef untuk menciptakan alias nama tipe data yang ramah dibaca!

💡

Analogi Santai untuk Pemula: Kotak Bento (Struct) vs Papan Tulis Kos (Union)!

Kenapa C++ butuh tipe bentukan? Biar kamu nggak bikin puluhan variabel tercecer sendirian:

🍱 Struct = Kotak Bento Ada sekat nasi, sekat lauk, sekat sambal. Masing-masing punya tempat sendiri, sambal pedas nggak bakal ngacak-ngacak nasi putihmu!
📋 Union = Papan Tulis 1 Kotak Cuma punya 1 papan tulis kecil. Kalau kamu nulis nomor HP, terus temanmu nulis daftar belanja di tempat yang sama, nomor HP-mu hilang ketimpa!
🔢 Enum = Daftar Antrean Bank Nama orang dikasih nomor antrean urut. Komputer otomatis mulai hitung dari angka 0 (Soekarno=0, Soeharto=1, dst.).
🏷️ Typedef = Nama Panggilan Kontak Nama KTP panjang "Warnisyah Armin", tapi di kontak dinamai "Ocha". Orangnya sama persis, cuma manggilnya jadi ringkas dan enak!
🏛️

4 Pilar Fondasi Tipe Data Bentukan (Kunci Responsi)

1. STRUCT Structure

Kapling Memori Terpisah

Membungkus berbagai variabel bertipe data sama maupun berbeda ke dalam satu wadah entitas. Setiap member memiliki alamat memori sendiri, sehingga nilai-nilai tidak saling mengganggu.

struct Mhs {
  string nama;
  int nim;
};
📌 Total Ukuran: Penjumlahan seluruh ukuran member (+ padding alinyemen RAM).
2. UNION Shared RAM

Satu Alamat Bersama (Overwrite)

Seluruh member berbagi satu alamat fisik memori yang sama persis. Dirancang untuk menghemat memori. Nilai member yang terakhir kali diisi akan menimpa (overwrite) nilai member lainnya!

union Nilai {
  float angka;
  char huruf;
};
📌 Total Ukuran: Hanya sebesar ukuran member terbesar saja (misal float = 4 B).
3. ENUM Enumeration

Konstanta Integer Mulai 0

Mendefinisikan kumpulan nama simbolis yang mewakili konstanta bilangan bulat. Secara default nilainya dimulai dari indeks 0 lalu bertambah +1 untuk setiap item berikutnya.

enum Presiden {
  Soekarno, // 0
  Soeharto, // 1
  Habibie   // 2
};
📌 Kunci Praktikum 3.3: Urutan ke-n didapat dengan namaPresiden + 1.
4. TYPEDEF Type Definition

Alias Nama Baru Tipe Data

Memberikan nama panggilan (alias) baru pada tipe data yang sudah ada, membuat kode program lebih mudah dipahami manusia dan mempersingkat sintaks deklarasi struct.

typedef float angkaPecahan;
typedef string kata;
angkaPecahan p = 10.5;
📌 Kunci Praktikum 3.5: Membantu penulisan rumus geometri balok jadi rapi.

Materi Ujian Responsi Modul 3

Modul 3 adalah gerbang awal pembuatan aplikasi dunia nyata. Simak bedah konsep di balik 4 pilar tipe bentukan C++ yang paling sering diuji oleh dosen:

🏛️ 1. Kenapa Butuh Tipe Bentukan? (User-Defined Types)

Tipe data primitif (int, float, char) cuma bisa menampung 1 jenis nilai tunggal:

  • Di dunia nyata, satu objek data punya banyak sifat (misal Mahasiswa punya Nama, NIM, Jurusan, IPK).
  • Tanpa struct, kalian harus bikin 4 variabel array terpisah yang rawan tertukar urutannya.
  • Dengan struct, kalian menciptakan tipe data baru rancangan sendiri yang membungkus semua atribut tersebut dalam satu kesatuan rapi!
struct Mahasiswa { string nama; int nim; float ipk; };
🧬 2. Struct vs Union: Beda 180 Derajat di Memori RAM

Kunci utama yang wajib kalian pahami saat responsi:

STRUCT (Kapling Terpisah): Setiap member punya alamat memori RAM mandiri. Ukuran memori = total seluruh ukuran member (+ padding alinyemen RAM). Semua nilai tersimpan aman tanpa saling ganggu.
UNION (Satu Alamat Bersama): Semua member berbagi 1 alamat fisik memori yang sama. Ukuran memori HANYA sebesar member terbesarnya! Nilai member terakhir yang kalian isi akan langsung menimpa (overwrite) member sebelumnya. Digunakan untuk sistem tertanam (IoT / mikrokontroler) yang RAM-nya super hemat!
🏷️ 3. Enum (Auto-Index) & Typedef (Nama Alias)

Dua alat bantu yang membuat kodemu bersih dan profesional:

  • Enum (Enumerasi): Memberi nama teks pada deretan angka bulat (default mulai indeks 0). Menghilangkan magic numbers agar program tidak rawan salah ketik logika (misal status GAGAL = 0, SUKSES = 1).
  • Typedef: Memberi nama panggilan (alias) baru pada tipe data. Sintaks: typedef tipe_lama nama_baru;. Bermanfaat untuk menyingkat penulisan tipe data panjang seperti unsigned long long int jadi uint64.
enum Arah { UTARA, TIMUR, SELATAN, BARAT }; // UTARA=0, TIMUR=1, dst.
⚠️ 4. Jebakan Batman & Kisi-Kisi Responsi Dosen
1. Lupa Titik Koma (;) di Akhir Struct/Union:
90% praktikan pemula lupa menaruh tanda ; setelah kurung kurawal tutup struct Mhs { ... };. Akibatnya compiler mengeluarkan error puluhan baris!
2. Cara Akses Member (Titik vs Panah):
Gunakan operator titik . untuk variabel struct biasa (contoh: mhs.nama). Operator panah -> hanya dipakai jika variabelnya berupa pointer!
3. Pertanyaan Dosen: "Berapa ukuran sizeof(union)?"
Jawab: HANYA sebesar ukuran member terbesarnya! Jika ada int (4B) dan double (8B), maka ukuran union adalah 8 byte.

Tipe Data String & Pustaka Bawaan <string>

Mengapa tipe data string begitu istimewa di C++? Pahami perbedaan arsitektur klasik C-String (Array of Char) dengan C++ std::string, kuasai teknik input spasi menggunakan cin.get(), dan jelajahi fungsi bawaan seperti .length(), .at(), .replace(), .find(), hingga swap()!

💡

Analogi Santai untuk Pemula: String Itu Gerbong Kereta Huruf!

String itu bukan satu benda utuh yang padat, melainkan rangkaian karakter yang digandeng berjejer seperti gerbong kereta api:

🚂 .length() atau .size() Kondektur yang jalan menghitung ada berapa gerbong penumpang. Kalau string "Nisa", ada 4 gerbong. Tanda batas akhir (\0) nggak ikut dihitung!
🎫 .at(index) vs teks[index] Kayak mencari nomor kursi penumpang. Bedanya, .at(idx) punya satpam penjaga: kalau nomor kursinya nggak ada di kereta, dia teriak ngasih peringatan (exception aman), bukannya bikin program crash!
🧹 cin >> vs cin.get() cin >> itu kayak anak kecil pemilih: cuma makan satu kata pertama, begitu ketemu spasi langsung mogok. Kalau cin.get() itu vacuum cleaner: sedot satu baris penuh kalimat beserta spasi!

Kupas Tuntas: Fungsi .length() & .size()

Di C++, fungsi .length() dan .size() adalah sinonim identik (menghasilkan angka yang persis sama). Keduanya merupakan method anggota dari kelas std::string yang bertugas menghitung jumlah byte/karakter aktif di dalam objek string.

1. Tanpa Menghitung Null-Terminator (\0):
Jika string berisi "Nisa", maka teks.length() bernilai 4. Karakter terminator pembatas akhir memori \0 tidak ikut dihitung.
2. Mengapa Ada Dua Nama (.length & .size)?
.length() diadopsi dari terminologi teks konvensional, sedangkan .size() disediakan agar konsisten dengan koleksi kontainer STL C++ lainnya (seperti vector, list, map). 
string nama = "Warnisyah Armin";
cout << "Panjang nama: " << nama.length() << " karakter"; // 15 karakter

Dilema Input Keyboard: Membaca Spasi (Laprak 4.1 vs 4.2)

Digunakan untuk C-String (char[]). Membaca kalimat utuh termasuk spasi hingga batas kapasitas memori yang ditentukan. Contoh: cin.get(nama, 50);.

3. getline(cin, str); (Standar Modern C++)

Digunakan untuk std::string. Membaca satu baris penuh kalimat berspasi hingga praktikan menekan tombol Enter.

Materi Ujian Responsi Modul 4

Tipe data string sering memicu bug aneh pada tugas praktikan karena karakteristik input stream keyboard. Simak bedah tuntas solusinya di bawah ini:

🧵 1. C-String (Array Karakter) vs C++ std::string

Memahami dua generasi tipe data teks di C++:

  • C-String (char str[50]): Cara kuno warisan bahasa C. Kapasitasnya kaku (*fixed*), rawan buffer overflow jika user menginput lebih dari 49 karakter, dan wajib diakhiri tanda batas \0 (ASCII null).
  • C++ std::string: Objek kelas modern dari #include <string>. Kapasitas RAM otomatis membesar sesuai kebutuhan (*dynamic*), mendukung operator + untuk sambung kata, dan punya metode bawaan lengkap!
string kalimat = "Teknik" + string(" Komputer"); // Mudah dan aman!
⌨️ 2. Mengapa cin >> Memotong Spasi? Solusi getline()

Operator ekstraksi cin >> memperlakukan spasi, tab, dan enter sebagai pemisah kata (*delimiter*):

Masalah cin >>: Kalau kalian ketik "Warnisyah Armin", yang masuk ke variabel cuma "Warnisyah". Kata "Armin" tertinggal di memori buffer keyboard!
Solusi: getline(cin, teks) Membaca seluruh baris kalimat beserta spasi sampai tombol Enter ditekan! (Untuk C-style char array, pakai cin.get(str, 50)).
👻 3. Misteri Hantu Enter & Penyelamat cin.ignore()

Pernahkah program kalian tiba-tiba melompati input nama setelah kalian menginput umur?

  • Saat kalian mengetik angka umur lalu menekan Enter, karakter \n (Enter) tertinggal di buffer keyboard.
  • Ketika program sampai di baris getline(cin, nama), fungsi ini langsung menyedot sisa Enter tersebut dan mengira kalian menekan Enter kosong!
  • Solusi Ampuh Asdos: Selalu tulis cin.ignore(); tepat setelah cin >> sebelum baris getline()!
cin >> umur;
cin.ignore(); // Membuang sisa tombol Enter!
getline(cin, namaLengkap);
⚠️ 4. Jebakan Batman & Kisi-Kisi Responsi Dosen
1. .length() vs .size():
Keduanya sinonim identik (hasilnya sama persis). Karakter null \0 tidak dihitung. Jadi string "Nisa" panjangnya adalah 4.
2. .at(idx) vs teks[idx]:
.at() jauh lebih aman karena memiliki *bounds checking* (melempar peringatan jika indeks melewati panjang teks, bukannya membuat program crash tertutup sendiri).
3. Menukar Teks Tanpa Variabel Ketiga:
Gunakan fungsi bawaan swap(teksA, teksB);! Eksekusi seketika menukar isi memori tanpa variabel penampung sementara.

Analogi Santai untuk Pemula: Percabangan Itu Cara Komputer Memilih!

Tanpa percabangan, program cuma kayak robot buta yang jalan lurus dari atas ke bawah. Dengan percabangan, program punya otak buat nanya: "Syaratnya terpenuhi nggak?":

1. if Tunggal (Satu Aksi)

Analogi Palang Kereta: Cuma bereaksi kalau kereta beneran lewat (kondisi TRUE). Kalau nggak ada kereta (FALSE), palang diam saja dan mobil lewat seperti biasa tanpa aksi khusus.

if (hujan) bawaPayung();
2. if - else (Dua Arah)

Analogi Lampu Merah: Pasti ada salah satu yang jalan! Kalau lampu hijau → maju. Selain itu (else / merah) → wajib berhenti. Nggak mungkin dua-duanya jalan bareng.

if (hijau) jalan(); else stop();
3. if - else if (Banyak Rentang)

Analogi Loket Masuk Dufan: Petugas cek dari atas ke bawah: ≤1m (tiket balita)? Kalau bukan ≤1.4m (tiket anak)? Kalau bukan ≤1.7m (tiket remaja)? Begitu cocok, langsung bayar & selesai!

if (u<=1) .. else if (u<=10) ..
4. switch - case (Pilihan Pasti)

Analogi Vending Machine: Masukkan koin lalu pencet tombol nilai pasti: Tombol 'A' keluar Cola, 'B' keluar Susu. Pencet tombol lain sembarang → masuk tombol 'default' (uang balik)!

switch(tombol) { case 'A': .. }

Materi Ujian Responsi Modul 5

Percabangan adalah otak pengambil keputusan di program kalian. Simak rangkuman prinsip dasar kontrol alur yang wajib dikuasai sebelum menghadapi dosen penguji:

🔀 1. Hirarki 4 Struktur Percabangan C++

Memilih jenis percabangan yang tepat sesuai kondisi kasus:

  • if Tunggal: Tindakan opsional. Blok kurung kurawal cuma jalan kalau syarat bernilai TRUE. Kalau FALSE, dilewati begitu saja.
  • if-else Ganda: Pilihan 2 arah yang saling meniadakan (*mutually exclusive*). Pasti salah satu dari kedua blok yang dieksekusi.
  • if-else if Majemuk: Pengecekan berantai banyak rentang. Begitu ada satu syarat TRUE yang cocok, blok di bawahnya langsung diabaikan.
  • switch-case: Menu pilihan berbasis nilai eksak (integer/char). Lebih bersih dan rapi daripada menulis belasan if bertingkat!
⚠️ 2. Bahaya Fall-Through Switch & Peran Kata Kunci break;

Di dalam switch, label case sebenarnya hanyalah penanda alamat lompatan kode (*jump target*):

Apa itu Fall-Through? Jika kalian lupa mengetik break; di akhir suatu case, eksekusi program akan terjun bebas mengeksekusi semua case di bawahnya meskipun nilainya tidak cocok sama sekali!
switch(grade) {
  case 'A': cout << "Istimewa"; break; // Wajib break!
  default: cout << "Tidak Valid";
}
🛍️ 3. Bedah Logika Program Kasir Diskon Bertingkat

Alur matematis pembuatan aplikasi kasir yang benar:

  • Rentang Diskon: Belanja ≥ Rp 500.000 (diskon 20%), ≥ Rp 250.000 (diskon 10%), ≥ Rp 100.000 (diskon 5%), di bawah itu 0%.
  • Rumus Potongan: Besar Diskon = Total Belanja * Persentase Diskon;
  • Rumus Bayar: Total Bayar = Total Belanja - Besar Diskon;
  • Uang Kembalian: Kembalian = Uang Diberikan - Total Bayar; (Jika uang kurang, tolak transaksi).
🎯 4. Titik Koma Beracun & Kisi-Kisi Responsi Dosen
1. Titik Koma Beracun Setelah 'if':
Jangan pernah menulis if (nilai >= 75); dengan titik koma di belakang kurung! Titik koma tersebut langsung mematikan if, akibatnya blok di bawahnya SELALU dicetak!
2. Urutan Rentang Pada 'else if':
Uji selalu dari rentang terbesar/paling ketat lebih dulu (≥ 500rb, baru ≥ 250rb, baru ≥ 100rb). Jika kalian balik dari yang kecil, angka 600rb akan salah masuk ke diskon terkecil!
3. Pertanyaan Dosen: "Bisakah switch memakai float / string?"
Jawab: TIDAK BISA di C++ standar! switch hanya menerima tipe data bilangan bulat diskrit (int, char, enum). Jika butuh rentang koma, wajib pakai if-else if.

Praktikum 5.4

switch-case Nilai Mata Kuliah

Mencocokkan huruf mutu nilai (A, B, C, D, E) ke case yang cocok. Wajib pakai break agar tidak tembus ke bawah! 

switch (nilaiMK) {
    case 'A': cout << "A"; break;
    case 'B': cout << "B"; break;
    default: cout << "Salah input!"; break;
}
💡 Karakteristik: Evaluasi nilai konstan karakter eksak dengan default fallback.
